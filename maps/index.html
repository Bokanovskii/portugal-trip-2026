Portugal lists for Google My Maps

Google Maps does not provide an API or bulk importer for personal Saved Lists. These CSV files are the supported practical alternative: import restaurant and shopping lists as regional layers in one Google My Map, which can then be viewed in the Google Maps app.

Do this on a computer: Google My Maps can be viewed on a phone, but creating and importing layers works best in a desktop browser.
  1. Download one or more regional CSV files below.
  2. Open Google My Maps, sign in, and click Create a new map.
  3. Click the map title and name it Portugal 2026 Restaurants.
  4. Rename “Untitled layer” for the region, such as Madeira, then click Import and upload that region’s CSV.
  5. When asked which column positions the markers, select Location.
  6. When asked which column titles the markers, select Name.
  7. Optionally choose Uniform style → Group places by → Guide status to color priorities, backups, and regional-specialty stops differently.
  8. Click Add layer and repeat for Porto, Douro/Central Portugal, and Lisbon.
  9. Click Share to give Kaya access or enable link sharing.

Important limitation

An imported Google My Map does not automatically resync when these CSV files change. To update a layer, download the newer CSV, open the layer’s three-dot menu, choose Reimport and merge, then Replace all items.

Open it on your phone

Use the same Google account in the Google Maps app, then open You or Saved → Maps. Your “Portugal 2026 Restaurants” My Map will appear there as an overlay.

The “Guide status” and “Why it is listed” columns are included in each marker description so priority and context survive the import.
