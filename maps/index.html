Restaurant lists for Google My Maps

Google Maps does not provide an API or bulk importer for personal Saved Lists. These CSV files are the supported practical alternative: import them as regional layers in one Google My Map, which can then be viewed in the Google Maps app.

One-time setup: on a computer, open Google My Maps, create a map, add a layer, and import a CSV below. Choose Location to position the markers and Name as the marker title. Repeat for each region.

Important limitation

An imported Google My Map does not automatically resync when these CSV files change. The download links remain stable, but after major guide updates you must replace or reimport the affected layer.

The “Guide status” and “Why it is listed” columns are included in each marker description so priority and context survive the import.
